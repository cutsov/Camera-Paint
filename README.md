# CAMERA-PAINT

An interactive canvas where you can draw in real time using hand gestures via your webcam!

## Before Using

This project uses third-party libraries listed in `requirements.txt`.
Install them with a single pip command:

```bash
pip install -r requirements.txt
```

## How to Use

- Draw on the right side of the screen; adjust the color on the left.
- If you hold up your middle and index fingers at the same time, an eraser tool will appear between them, which you can use to erase your drawing.
- By touching your thumb and index finger together, you can move the sliders on the left: color, saturation, and brightness.
- To switch tools, touch your thumb and index finger together and hover them over the tool-switch button in the upper-right corner
